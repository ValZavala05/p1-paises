# P1 · Buscador de países

Página que consulta la API REST Countries (v5) con `fetch` y muestra bandera, capital, región y población de cada país.

## Cómo ejecutarla
1. Se crea una cuenta y una API key en https://restcountries.com/sign-up
2. En la llave, se agrega `127.0.0.1, localhost` en CORS Allowed Origins.
3. Se copia `config.example.js` como `config.js` y se pega la llave.
4. Abre `index.html`.
